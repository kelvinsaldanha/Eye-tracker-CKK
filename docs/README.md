# Guia rápido de atualização

Leia o README na raiz. Para adicionar instalador e vídeo, abra `configurar.html` pela hospedagem ou pelo servidor local, escolha os arquivos/links e gere o pacote atualizado.

## Verificação antes de publicar

- Confira os nomes, as fotos e os links da equipe.
- Use o executável corrigido da versão 0.1.2, ou atualize os dados para a nova compilação.
- Teste o download e confira o SHA-256 do arquivo exato.
- Assista ao vídeo e confira as legendas, se houver.
- Envie o conteúdo extraído do ZIP, mantendo `index.html` na raiz do GitHub Pages.

As melhorias de inicialização da câmera e tradução do instalador foram analisadas, mas não constavam como implementadas no registro de 19/10/2026.
